# Dota Accepter

Помощник для Dota 2 на Windows: обнаруживает кнопку принятия игры и отправляет Enter только в активное окно Dota 2. Telegram и Алиса — необязательные подключения, которые каждый пользователь настраивает самостоятельно.

## Запуск из исходников

Проверено на Windows с Python 3.11 x64. Для запуска нужны Python и зависимости; одного скачивания ZIP недостаточно.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Запускайте команды из папки проекта. Шаблоны и стандартные звуки включены в репозиторий. Игра должна быть видима и активна. Масштаб, разрешение и изменения интерфейса Dota 2 могут потребовать замены шаблонов в настройках.

## Настройки и подключения

При первом обычном запуске автоматически создаётся `config.json` рядом с исходниками; у собранного EXE — рядом с EXE. Это разные файлы настроек. Папка должна быть доступна для записи.

Токены отсутствуют в репозитории. После успешной настройки они сохраняются через Windows DPAPI для текущего пользователя. Не переносите личный конфиг на другой компьютер: подключите сервисы заново. Выключение оповещений не удаляет токены; кнопка «Удалить подключение» требует подтверждения.

- **Звук:** включается на главной или в разделе «Звуки».
- **Telegram:** создайте своего бота, привяжите личный чат и отправьте тестовое сообщение.
- **Алиса:** получите OAuth access_token с правами `iot:view` и `iot:control`, загрузите сценарии, выберите сценарий и проверьте запуск. Client Secret не нужен в поле токена.
- После проверки включите нужные оповещения на главной. Изменять настройки можно при остановленном ожидании.

Telegram и Алиса начинают отправку при обнаружении кнопки принятия, до Enter, независимо друг от друга. Реальная доставка зависит от сети и сервисов. Тест Алисы выполняет реальные действия сценария. Отправка скриншота Telegram отключена по умолчанию; при включении захватывает весь экран.

Insert по умолчанию запускает и останавливает ожидание при отпускании клавиши. Сочетание можно изменить в «Управлении». В режиме проверки программа продолжает ждать экран выбора героя; отправленный Enter сам по себе не подтверждает принятие матча.

## Проверки разработчика

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest tests -q
.\.venv\Scripts\python.exe main.py --ui-check qa/evidence/local
```

Тесты используют временные настройки и подменяют сеть, ввод и захват экрана. Изолированная проверка интерфейса не запускает поиск матча и не использует личные подключения.

## Сборка по явной необходимости

`build_exe.bat` использует PyInstaller и `accepter.spec`. Сначала активируйте окружение с установленными зависимостями. Результат: `dist/portable/Accepter.exe`. Конфиг и импортированные звуки не включаются в сборку.

Известное ограничение: после начала сетевого запроса остановка не может отменить уже отправленное действие. Ошибки доставки отображаются отдельно от результата распознавания.
